# 文件分片阶段：发现并核实候选

应用共享专家视角，逐个检查本片的全部变更；可读取必要的相关消费者，不扩展为无边界的全仓审查。检查通过只能证明实际执行及断言覆盖的路径。

每个候选先核对触发条件、base/head 变化、调用方约束和反例，再按证据强度归类。需要其他分片的调用方、锁域或失败路径才能判定时，保留为 observation，写明已知证据、具体缺口和下一步；由全局复核补查。源码能闭合证明的缺陷不要求一定实际复现；测试通过不自动排除未覆盖的行为问题。

使用本片真实存在的 LEFT/RIGHT 行；完整检查的路径写入 files_reviewed。输出发现与可复用事实，在 investigation_log 的源码事实中简短标明对应视角与查到的约束，不输出逐个专家的报告。不自行发布评论。
